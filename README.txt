Alfred — trading journal (standalone)

On iPhone:
1. Open this zip in the Files app and tap it to extract the "Alfred" folder.
2. Open the folder, long-press index.html and choose Share, then Safari
   (or tap it, then use the Share button and choose Safari).
3. In Safari, tap Share, then "Add to Home Screen" (or "Add Bookmark").
   The icon and the name "Alfred" are already set.

Notes:
- This copy keeps its data in Safari's storage on this phone. It does not sync
  with the version at claude.ai; if you want sync across devices, bookmark that
  link instead.
- The fonts are Apple's own on iPhone. An internet connection is only used for
  the Inter fallback font on non-Apple devices.
